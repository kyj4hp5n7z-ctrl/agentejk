# VendaFlow AI

Projeto em Next.js para gerar anúncios com IA para Mercado Livre, Shopee, Facebook, Instagram, WhatsApp e Feira do Rolo.

## Como rodar no notebook

```bash
npm install
npm run dev
```

Depois abra:

```text
http://localhost:3000
```

## Como criar o link público

1. Crie uma conta no GitHub.
2. Suba essa pasta para um repositório.
3. Crie uma conta na Vercel.
4. Clique em Add New Project.
5. Escolha o repositório VendaFlow AI.
6. Clique em Deploy.

A Vercel vai gerar um link parecido com:

```text
https://vendaflow-ai.vercel.app
```

## Observação

A API está com resposta simulada para validar o fluxo.
Depois pode conectar com OpenAI API usando uma variável de ambiente OPENAI_API_KEY.
